
# Sistema de Gestión de Solicitudes de Soporte Técnico

## Descripción
Sistema web para registrar y consultar solicitudes de soporte técnico.

## Tecnologías utilizadas
- PHP
- MySQL
- HTML y CSS
- XAMPP
- Git

## Funcionalidades actuales
- Registro de tickets de soporte.
- Asignación automática de un identificador único.
- Selección de categoría y prioridad.
- Consulta de tickets registrados.
- Filtrado de tickets por estado, categoría, prioridad y fecha.

## Instalación y ejecución
1. Instalar XAMPP.
2. Iniciar Apache y MySQL.
3. Crear la base de datos `soporte_tecnico` en phpMyAdmin.
4. Crear la tabla `tickets` con la estructura del proyecto.
5. Colocar la carpeta del proyecto en `C:\xampp\htdocs\soporte-tecnico`.
6. Abrir `http://localhost/soporte-tecnico/` en el navegador.

## Control de versiones
El proyecto utiliza Git para registrar cambios y administrar ramas.
